📺 ZooTube
Nowoczesna platforma do streamowania wideo inspirowana serwisem YouTube. Projekt łączy potęgę Spring Boota na backendzie
z frontendem na bazie Angulara i bazach danych takich jak PostGreSql i MongoDB.

🚀 O projekcie
Jest to projekt stworzony, aby kontynuoować naukę FrameWorka SpringBoot i Angulara. W trakcie pisania wykorzystywałem jak najmniejszą ilość 
sztucznej inteligencji, aby jak najwięcej z tego projektu wynieść. Projekt nie jest przeznaczony komercyjnie.


✨ Kluczowe funkcjonalności
Aplikacja pozwala użytkownikom na przesyłanie, oglądanie oraz interakcję z treściami wideo. Użytkownik ma swój własny kanał, 
który może edytować w zakładce "Mój kanał. Użytkownicy mogą komentować filmy innych użytkowników, co powoduje wysłania powiadomień do twórcy 
filmu. Użytkownicy mają dostęp do tworzenia,usuwania i edytowania playlist, każdy użytkownik ma domyślnie playliste "Historia".

🛠Technologie

Backend:
* SpringBoot
* Backend
* Java 17+ 
* PostgreSQL
* MongoDB

Frontend:
* Angular
* TypeScript
* Html, Css

🛠
Jak uruchomić:
* 1. Posiadać zaintalowanego docker
  2. w terminalu wejść do folderu projektu
  3. wpisać: docker-compose up --build
